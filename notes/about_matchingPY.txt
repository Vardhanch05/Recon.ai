File Summary (One-Paragraph Note)
backend/matching.py contains the high-speed deterministic reconciliation engine that achieves an ~80% match rate without calling any external LLMs. 
It operates in two stages: (1) Primary Path: exact null-safe order_id matching with fee-adjusted monetary sanity checks (gross amount vs billed price within ±₹0.02 tolerance); and 
(2) Fallback Path: searches for orphan settlement records by matching fee-adjusted amounts within a configurable timestamp window (±timestamp_tolerance_seconds). 
It automatically routes exact matches to matched_deterministic and tags discrepancies with precise RoutingReasons (amount_mismatch, ambiguous_multiple, no_match, currency_mismatch), 
populating candidate links into exception_candidates for the AI Reasoner.

🔑 Key Concepts, Types & Functions Used

1. 2-Stage Matching Architecture (Primary vs Fallback)
   • Stage 1 (Order ID Path): Direct O(1) in-memory hash map lookup by order_id. Fast and 100% accurate.
   • Stage 2 (Fallback Path): For gateway records missing order_id, searches for ledger entries matching amount within a sliding time window (timedelta).

2. Mathematical Sanity Check (abs(settled + fee - billed) <= 0.02)
   Prevents false-positive matches where the order_id is identical, but the gateway underpaid or deducted unexpected fees.

3. Ambiguous Multiple Handling (RoutingReason.ambiguous_multiple)
   If multiple ledger orders share the exact same amount and timestamp, the engine refuses to guess blindly. It creates an ExceptionCandidate row for every potential order so the AI Reasoner can evaluate payment methods or customer metadata.

4. Claimed Ledger Set (matched_ledger_ids)
   Tracks matched orders in-memory to prevent the same merchant order from being matched against multiple settlement payouts (double-counting prevention).

5. Batch Metrics & Audit Logging
   Atomically updates BatchStatus to matching_complete, computes match_rate_deterministic, and logs a match audit event to audit_log.

💡 Explainability Tip for Interviews / Project Reviews

Your answer:
